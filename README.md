# TaskFlow — Task Manager

A simple task manager built with HTML, CSS, and JavaScript. Add tasks with due dates, priorities, and categories. Filter, search, and sort your tasks, mark them done, and track progress with a stats dashboard. No setup needed — just open in a browser. Data saves automatically in the browser.

## Features

- Add tasks with due dates, priority levels, and categories
- Mark tasks complete, edit inline, or delete
- Filter by All, Pending, Done, and Overdue
- Real-time search and sorting
- Stats dashboard with progress bar
- Data persists via localStorage

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## How to run

Download `todo-app.html` and open it in any browser. No installation required.
